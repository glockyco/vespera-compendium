## 1. Executive summary

**Everything of consequence is client-side, local, and editable.** Of 68 audited systems, 60 are
purely local, 5 are hybrid (local gameplay + additive server layer), and 3 are social-only.

1. **Entity counts are composed at runtime, not declared.** Every headline table is assembled from a
   base literal plus overlays, pushes and filters. `@vespera/pipeline` reproduces those transformations,
   and `@vespera/harness` verifies their live cardinality and deterministic record samples. A
   literal-only scraper is wrong on all six composed tables.
2. **Almost nothing is lost by playing offline — but Caravans regressed in 24432331.** World Boss
   still resolves entirely client-side (schedule, outcome roll, all eight exclusive `wb_*` pieces), and
   chat/mailbox/cloud carry no content. However the `caravans.allowLocalFallback` flag flipped
   `true → false` in `index.html`, so Crownroad Caravans now go **unavailable** when the server is
   unreachable instead of resolving locally. This is a one-word revert on the highest-durability
   modding surface — see the Caravans record.
3. **Leaderboards are switched off in this build.** `LEADERBOARDS_PAUSED = true` and
   `LEADERBOARDS_MENU_ENABLED = false` (`GameView-Bdbw4Cpc.js:115831-115832`). The leaderboard
   integrity concern is therefore currently moot, though the `isDevMode` quarantine remains correct.
4. **Playing outside Steam *unlocks* content.** Riftmarch's gate is `enabled && !isSteamBuild`.
5. **Dominion is a complete, shipped, fully local 19th system**, absent from the in-game
   current-systems list. Own currency, own shop, six maps, NPC-populated ladder, Combat Level 20 gate.
6. **A large amount of shipped cosmetic content is unreachable.** 40 of 41 frames, 29 of 45 portraits
   and 8 of 9 themes cannot be obtained because `unlockCosmetic`, `checkCosmeticUnlocks` and
   `spendGemsForCosmetic` are no-ops (`index-D6527GFL.js:107553-107603`).

### Combat Formulas and Major Caps

- **Status**: current
- **Gate**: none; formulas apply where the relevant combat profile/stat/effect exists.
- **Summary**: The online combat resolver handles normal attacks, abilities, defense, crits, multi-hit, DoT ticks, healing/lifesteal, mana regeneration, haste/interval timing, and incoming mitigation. Offline `Sa.calculateDamage` is a separate resolver.
- **Bundle location**: `index-D6527GFL.js:75623-77172` (`bt.buildCombatProfile`, `resolvePlayerAttack`, `resolveSingleHit`, `resolveEnemyAttack`, `resolveTickDamage`); `index-D6527GFL.js:81912-81955` (primary/ability/haste helpers); `index-D6527GFL.js:79660-79700` (`getBaseManaRegenPerSecond`, `yr`); `index-D6527GFL.js:97589-97593` (final caps/scales); `GameView-Bdbw4Cpc.js:61352-61488` (active normal base damage and resolver call).
- **Locality**: local — all inspected resolver/profile/stat functions run in the client combat loop; no server combat calculation is observable [INFERENCE].
- **Key formulas/constants**: Design normal attack is `primaryMultiplier = 1 + Primary / (Primary + 500); rawAttack = Attack * primaryMultiplier`. ### Method notes

- **Never address by line number or filename.** Build 24420627 shifted every line in both bundles, and
  the bundle filenames did **not** change despite their contents changing — the build cache-busts with
  `?v=` query strings in `index.html` instead. Everything in `tools/` locates by content anchor, which
  is why it survived the mid-audit update unmodified.
- **Extraction**: `resources/app.asar` is an unencrypted asar with a plain JSON header; a byte-exact
  repack round-trip was verified on the earlier build (3273 packed files, 0 mismatches).
- **Counting**: every count is programmatic. Where a runtime merge or filter changes the effective
  value, §2 reports the composed value and the harness verifies live cardinality plus deterministic
  scalar record samples.
- **Verified stable across all four builds (24407752 → 24420627 → 24432331 → 24460838)**: the Electron
  fuse wire is unchanged at `101100011` (stock defaults — `AsarIntegrityValidation` and
  `OnlyLoadAppFromAsar` still DISABLED, `RunAsNode` and `NodeCliInspect` still ENABLED);
  `saveCrypto.cjs`, `saveNamespace.cjs` and `saveStorage.cjs` byte-identical throughout; the
  `devTools: !app.isPackaged || isSmokeTest` gate unchanged; runtime feature flags unchanged since
  24432331; and no integrity, checksum, signature, debugger-detection or anti-tamper code has ever been
  added. Every conclusion in this document about modding feasibility has held across four builds.
- **Changed in 24460838** (+124 files, 216 → 252 MB): new Wings cosmetic system; 96 avatar-pack art
  files; four new fishing nodes with 8 items and 4 recipes; `assets/crafting-chain-planner.js`;
  `electron/pageScale.cjs` with page-scale plumbing in `main.cjs`/`preload.cjs`; header quick-access
  keybinds; item search normalization; expanded Codex ("COMPLETE CLASS ENCYCLOPEDIA", "COMPLETE ELEMENT
  ENCYCLOPEDIA") and `assets/localization/endgame-codex-overrides.js`; `assets/brand/vespera-roadmap-v2.png`.
  **Balance**: defense mitigation preserves its calculated value through attacker level 256 and applies

  Supabase Edge Function source and RLS policies are unknown. Unobserved claims are marked `[INFERENCE]`.
